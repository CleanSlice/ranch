# Data Model: Upgrade operator consoles off Nuxt 3 EOL

**Date**: 2026-08-14 · **Plan**: [plan.md](./plan.md) · **Research**: [research.md](./research.md)

No database entities. The “model” is the frontend platform and the slice graph that must survive it.

## Frontend platform (per console)

Each of `app/` and `admin/` is a Nuxt host with the same lifecycle.

| Field | Today | After Stage A | After Stage B (shipped) |
|-------|-------|---------------|-------------------------|
| Nuxt major | 3 (locked 3.21.2) | 3.21.2 | **4** |
| `future.compatibilityVersion` | unset | **4** | 4 (Nuxt 4 default) |
| `ssr` | `false` | `false` | `false` |
| Directory convention | v3-flat (root `srcDir`) | v3-flat (auto-detect or `srcDir: '.'`) | v3-flat (D1) |
| Layer composer | `registerSlices()` → `extends` | same | same |
| Typecheck command | none | none (optional dry-run) | `nuxt typecheck` required green |

```text
Nuxt 3.21 (EOL)
    │  Stage A: compatibilityVersion 4, modules unchanged
    ▼
Nuxt 3.21 + v4 defaults   ← SC-007 checkpoint (must be green)
    │  Stage B: bump nuxt + coupled modules
    ▼
Nuxt 4                    ← SC-006 shipped state
```

**Invariant**: a console MUST NOT sit on mixed majors (host Nuxt 4 + slices still requiring Nuxt 3-only modules). Both hosts move together (D11).

## Slice (layer)

A slice is a directory with `nuxt.config.ts` discovered by `registerSlices.ts`.

| Attribute | Rule |
|-----------|------|
| Identity | Path relative to the host (`./slices/setup/i18n`, `./slices/agent/agent`, …) |
| Required file | `nuxt.config.ts` (presence = layer) |
| Optional trees | `pages/`, `components/`, `stores/`, `plugins/`, `middleware/`, `layouts/`, `composables/`, `domain/`, `data/`, `locales/` → `i18n/locales/` |
| Public alias | Optional `#name` pointing at the slice root (must still resolve after the upgrade) |
| DI surface | Optional `index.d.ts` augmenting `#app` |
| Locale messages | English JSON; after D4: `<slice>/i18n/locales/en.json` |
| Count | **11** in `app`, **28** in `admin` — SC-001: zero dropped |

**Load order** (must not change):

1. All layers under `./slices/setup`
2. `./slices/common`
3. Remaining feature layers, recursive, as today

Parent folders without `nuxt.config.ts` (`slices/setup`, `slices/agent`, `slices/user`) are **groups**, not layers.

## Coupled module (version matrix)

| Module | Role | Stage A | Stage B |
|--------|------|---------|---------|
| `@nuxtjs/i18n` | localization | `^9` | `^10` |
| `@pinia/nuxt` | store module | `^0.9` | `^0.11` |
| `pinia` | store runtime | `^3` (direct dep) | `^3` (direct dep, required) |
| `shadcn-nuxt` | UI kit module | current 2.x | latest 2.x that supports Nuxt 4 |
| `@nuxt/image` | image module (unused in templates) | `^1` | `^1` compatible with Nuxt 4 |

A module with no Nuxt 4-compatible release **blocks** Stage B (spec edge case). Record the gap; do not ship Nuxt 4 without it.

## Locale file (per slice)

| State | Path used at runtime |
|-------|----------------------|
| Today (wired) | `<slice>/locales/en.json` via `langDir: 'locales'` (`restructureDir: false`) |
| Drift | some slices also have `<slice>/i18n/locales/en.json` (sometimes different) |
| Broken | some admin slices declare `langDir: 'locales'` but only have `i18n/locales/` |
| Target (v10) | `<slice>/i18n/locales/en.json`; `restructureDir` left at default `'i18n'` |

**Merge rule**: currently wired `locales/` content wins; copy onto `i18n/locales/`; delete the unused duplicate. Setup-layer Vue I18n config moves under that layer's `i18n/` directory.
